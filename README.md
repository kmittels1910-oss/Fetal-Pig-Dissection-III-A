# Virtual Dissection: Fetal Pig

An interactive, self-contained HTML activity. Students pick up forceps, pull back the skin and muscle wall, lift the intestines, and identify organs by touching them with the forceps tip.

- No installation or external files needed: everything is in `index.html`.
- Works with mouse or touch in any modern browser.
- Simplified schematic. Follow your lab manual for anatomy details.

## Embed in Canvas

```html
<iframe src="YOUR-GITHUB-PAGES-URL" width="100%" height="900" style="border:0;" title="Virtual fetal pig dissection" allowfullscreen></iframe>
```
